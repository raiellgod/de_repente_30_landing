# De Repente 30 — Landing Page Comemorativa

Landing page criada como um presente pessoal de aniversário, inspirada na atmosfera visual e romântica do filme **De Repente 30**.

O projeto transforma uma homenagem pessoal em uma experiência web, combinando textos, imagens, referências afetivas e uma identidade visual temática.

## Objetivo

Criar uma página simples, personalizada e visualmente marcante usando apenas tecnologias fundamentais do front-end.

## Tecnologias

- HTML5
- CSS3

## Destaques

- Layout temático inspirado em *De Repente 30*
- Seções para mensagens, fotos e lembranças
- Composição visual voltada para uma experiência afetiva
- Uso de imagens e tipografia para reforçar a identidade da página
- Projeto publicado com GitHub Pages

## Estrutura

```text
.
├── imagens/
├── index.html
└── style.css
```

## Aprendizados

Este projeto foi um exercício de transformar uma ideia pessoal em uma interface web completa, trabalhando principalmente:

- estruturação semântica com HTML;
- organização visual com CSS;
- composição de seções;
- hierarquia de conteúdo;
- adaptação de uma referência visual para uma página autoral.
